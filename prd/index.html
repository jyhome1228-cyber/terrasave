02

BACKGROUND

프로젝트 배경과 제품 정의

실험실의 기술이 실제 유통 환경에서 어떤 가치로 작동하는지 명확하게 전달한다.

TerraSave는 Terracle의 에틸렌 포집 기술을 PET·PE 기반 기능성 포장재로 연결하는 브랜드입니다. 웹사이트는 기술 설명에 머무르지 않고, 유통 손실이라는 문제에서 제품 적용과 B2B 문의까지 자연스럽게 이어져야 합니다.

PROBLEM기술의 가치가 어렵게 인식됨

비전문 사용자의 빠른 이해를 위한 에틸렌 포집 및 소재 적용 원리의 구조화가 필요합니다.

SOLUTION문제 → 기술 → 제품의 서사

손실 데이터와 적용 과정을 구조화해 제품의 필요성과 도입 가능성을 연결합니다.

OUTCOME샘플·견적·공동연구 문의

사용자 목적에 맞는 문의 유형을 제공해 실질적인 B2B 리드로 전환합니다.

FUNCTIONAL SPECIFICATION

공통 및 핵심 기능 명세

GLOBAL공통 UI

헤더, 모바일 메뉴, 푸터, 로고, 활성 메뉴 표시를 모든 공개 페이지에서 동일하게 사용합니다.

DATA과일 DB

18개 과일 데이터를 JavaScript 데이터셋으로 관리하고 목록과 상세 화면에 동적으로 출력합니다.

CONVERSION상담 연결

정보 탐색 후 포장 상담으로 이어지도록 주요 페이지와 과일 상세에 CTA를 배치합니다.

FN-008FRUITS과일 개수 표시현재 필터 결과의 품목 수를 실시간으로 표시한다.필터 결과 개수와 표시 수량이 항상 일치LIVE
FN-009FRUIT DETAILURL 기반 과일 상세fruit.html?fruit={slug} 쿼리값으로 해당 과일 정보를 찾아 상세 페이지 전체를 동적으로 생성한다.유효 slug는 해당 품목 표시, 미지정·오류 값은 기본 품목으로 안전 처리LIVE
FN-010FRUIT DETAIL상세 데이터 출력보관 온도, 습도, 익는 방식, 에틸렌 영향, 관리 중요도, 주요 리스크와 포장 방향을 출력한다.데이터셋 변경 시 상세 화면이 별도 HTML 수정 없이 반영LIVE
FN-011FRUIT DETAIL과일 이미지 전환등록된 전체컷·단면컷이 있으면 2개 이미지를 표시하고, 없으면 기본 과일 그래픽으로 대체한다.이미지 데이터 유무에 관계없이 레이아웃이 깨지지 않음LIVE
FN-012FRUIT DETAIL이전·다음 과일현재 데이터 순서를 기준으로 이전·다음 품목 링크를 제공하며 마지막 품목 이후에는 처음으로 순환한다.18개 품목 전체에서 끊김 없이 순환 탐색LIVE
FN-013HOME대표 과일 자동 구성홈에서 지정한 대표 과일 6종을 우선 노출하고 누락 시 데이터 목록에서 자동 보충한다.항상 최대 6개 카드가 정상 출력되고 상세로 연결LIVE
FN-014CONTENT페이지별 카피 로컬라이징공통 main.js에서 메뉴명, 버튼, 메타 정보와 주요 문구를 한국어 서비스 문맥에 맞게 정리한다.영문 임시 문구가 주요 사용자 화면에 노출되지 않음LIVE
FN-015SEO동적 메타 정보페이지 유형과 과일 slug에 따라 title과 meta description을 갱신한다.과일 상세별 고유 제목 및 설명이 브라우저에 반영LIVE
FN-016ACCESSIBILITY접근성 상태 제공nav aria-current, menu aria-expanded, 이미지 alt, aria-live 영역 등 탐색 상태를 보조기기에 전달한다.핵심 인터랙션에 의미·상태 정보가 제공됨LIVE

기능 상태는 현재 GitHub Pages 운영 소스를 기준으로 기록합니다. 신규 데이터베이스, 관리자 기능, 서버 저장이 추가될 경우 별도 버전으로 확장합니다.

SUBMISSION LOGIC
  1. 문의 유형 선택 여부 확인
  2. 브라우저 기본 유효성 검사 실행

SYSTEM RULES

디자인·반응형·접근성 기준

DESIGN

절제된 기술 브랜드

블랙·화이트를 기반으로 #E95A20을 제한적으로 사용합니다. Pretendard, 1440px 컨테이너, 명확한 선과 여백을 공통 언어로 유지합니다.

RESPONSIVE

콘텐츠 우선 재배치

1100px에서 전역 메뉴를 축소하고, 760px에서 다단 그리드를 단일 열 또는 가로 탐색 구조로 전환합니다.

ACCESSIBILITY

의미와 상태 전달

시맨틱 구조, 이미지 대체 텍스트, 폼 레이블, aria-live 오류 안내, 키보드 탐색과 감소 모션 설정을 지원합니다.

SEO

페이지별 검색 문맥

고유 title과 description, 올바른 heading 구조, 실제 텍스트 콘텐츠를 유지하며 핵심 페이지 간 내부 링크를 제공합니다.
