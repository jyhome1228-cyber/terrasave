통계 안내

PV(페이지뷰)는 페이지가 조회된 횟수입니다. 서로 다른 사람 수(UV)가 아니며, 전체 탭은 국문·중문 페이지를 합산합니다. 언어별 탭의 페이지 목록은 URL 기준으로 분리하며, 일별 언어별 통계는 서버가 별도로 제공할 때만 표시할 수 있습니다. 개인정보 및 IP 주소는 이 대시보드에 표시하지 않습니다. 배포 이후 방문만 반영됩니다.
